SSH / TCP mock
==============

Install (once)
  1. Python 3.9+ from python.org  — check "Add python.exe to PATH"
  2. Double-click install-dependencies.bat
  3. Allow inbound TCP 2222 in Windows Firewall (SSH server tests)

Crestron CLIENT test  (processor connects to this PC over SSH)
  1. Double-click start-ssh-server.bat
  2. Set Client module:
       IP_Address$ = LAN IP printed by the server (not 127.0.0.1)
       IP_Port     = 2222
       Username$   = crestron
       Password$   = crestron
       Accept_Any_Key = Yes
  3. Hold Connect
  4. Type here to send; [RX] is data from the processor

Inbound TCP on the processor (built-in TCP/IP Server symbol)
  1. Enable TCP/IP Server in SIMPL, note its port (e.g. 5000)
  2. Double-click start-tcp-client.bat
  3. Enter processor IP and that port
  4. Type here to send; [RX] is data from the processor

Other
